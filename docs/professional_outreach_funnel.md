## Email Structure

Every outreach email should be short and specific:

1. Source context: where the prospect was found and why it is relevant.
2. Specific problem: one observed workflow, security, or handoff issue.
3. Fixed offer: USD 100, one narrow workflow or one authorized review.
4. Boundary: no production probing, no unauthorized access, written scope required.
5. Proof links: profile, relevant practice page, services page, start page.
6. Clear next action: reply with the first scope or authorize a small review.

## Link Rules

For workflow/agency offers, include:

- Services
- Start page
- Profile

For AI/security offers, include:

- Security page
- Services
- Start page
- Profile

For responsible disclosure, include:

- Security page
- Profile
- Services
- Start page

Do not include raw secret values or exploit details in email. Offer to share exact context privately after the recipient confirms the right channel.
