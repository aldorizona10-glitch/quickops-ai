# Global Outreach Plan

Target: get the first USD 100 from an international client.

Primary offer: one fixed workflow for USD 100.

Workflow examples:

- Gmail/Stripe invoice reply -> Google Sheet/CRM -> reminder email.
- Website/contact form -> HubSpot/Google Sheet -> first-reply template.
- Support inbox -> ticket status -> drafted response -> follow-up reminder.
- Prospect list -> enrichment checklist -> CRM import -> outreach draft.
- Content/video -> lead magnet -> email capture -> 3-message follow-up.
