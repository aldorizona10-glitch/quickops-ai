## Reddit Helpful Reply - Zapier Broke

When a Zapier workflow breaks, I usually check four things:

1. Did the trigger still fire?
2. Did field names change?
3. Did the action app reject a required field?
4. Is there a log/status field so failures are visible?

For small businesses I prefer a simple fallback: every automation writes to a Google Sheet or CRM status column so nothing disappears silently.
